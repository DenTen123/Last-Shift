# Обновлённые модели

Открывайте корневой project.godot. После импорта папки models/updated перезапустите сцену.

Загрузчик scripts/models.gd предпочитает подготовленные модели из models/updated. Если их нет, остаётся исходное подключение из models. Пользовательские экспорты не перезаписаны, вложенный luk30_3d не менялся.

Заменены: автомобиль, пешеходные ворота (дверь1 — полотно, дверь2 — рама), грядка (грядка1 — основание, грядка2 — полив, грядка3 — лампа), аптечный шкаф, доска инструментов, знак опасности, плавильная печь, верстак, измельчитель, койки, кухня, кушетка, телевизор, нож, шкафчик, стол (новый столик).

Экспортные смещения относительно общей сцены сняты, игровые позиции и взаимодействия сохранены. В машине выбраны только автомобильные узлы; мелкие детали салона скрываются вместе с ещё не установленной кабиной. Растения и плоды грядки сохранены из прежней модели. Автомобильные ворота, архитектура бункера, лестница и стеллаж не заменялись, поскольку соответствующих отдельных новых моделей не обнаружено.

Вложенным узлам заменённых моделей присвоена новая версия ключей раскладки: старые преобразования деталей по индексам к ним не применяются. Расстановка родительских объектов сохраняется. Старые записи деталей остаются в исходном сохранении до следующего сохранения раскладки; при необходимости перед запуском сделайте копию user://bunker_layout.json. Автоматического переноса ручных правок отдельных старых деталей на новую геометрию нет.

Повторная подготовка: Python запускает .sharrowkin/scripts/build_model_updates.py. Проверка воспроизводимости: тот же скрипт с --check. Скрипт пишет только models/updated. Проверка подключений и грамматики: .sharrowkin/scripts/check_model_updates.py с Python 3.12, где установлен локальный gdtoolkit.

Проверки без движка не подтверждают импорт, внешний вид, обзор через новое окно ворот и соответствие размеров старым коллайдерам. Это необходимо проверить в Godot. Новые формы могут отличаться от прежних зон взаимодействия.
