# Last-Shift
3D-симулятор выживания и управления бункером. Отправляйте команду на опасные вылазки за ресурсами, принимайте и проверяйте выживших, следите за запасами еды и здоровьем команды, стройте и улучшайте мастерские. За 30 дней соберите необходимые детали, восстановите автомобиль и выберитесь из убежища.
